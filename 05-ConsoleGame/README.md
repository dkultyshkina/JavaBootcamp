# :zero::five:-ConsoleGame

![Java](https://img.shields.io/badge/Java-Solutions-orange.svg?style=flat&logo=openjdk&logoColor=white) 

Командный проект совместно с **aydar-gafarov**.

Выполнение учебного проекта, направленного на создание консольной игры с использованием технологии Maven, в которой игрок будет убегать от объектов "искусственного интеллекта" (врагов), обходя препятствия по квадратному полю.  Программа генерирует случайную карту с препятствиям, местоположением игрока и его врагов. Учитывается, что в зависимости от положения игрока, враги будут его преследовать и менять стратегию движения.

Для запуска программы требуется ввести команду с аргументами командной строки:

**java -jar Game.jar --enemiesCount=\*количество врагов на поле\* --wallsCount=\*количество препятствий (стенок)\* --size=\*размер квадратного поля size на size\* --profile=\*режим игрока или разрабочика\***

## Результат выполненного задания:
Консольная игра (**ConsoleGame**)
