# :zero::zero:-BasicLanguageConstructs

![Java](https://img.shields.io/badge/Java-Solutions-orange.svg?style=flat&logo=openjdk&logoColor=white) 

Выполнение учебного проекта, направленного на изучение базовых конструкций языка Java (версия 1.8).

## Результат выполненных заданий:
1. Сумма чисел (**ex01_TheSumOfTheNumbers**)
2. Простое число (**ex02_PrimeNumber**)
3. Бесконечная последовательность (**ex03_InfiniteSequence**)
4. Немного статистики (**ex04_SomeStatistics**)
5. Немного больше статистики (**ex05_BitMoreofStatistics**)
6. Расписание (**ex06_Schedule**)
