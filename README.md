# JavaBootcamp

![Java](https://img.shields.io/badge/Java-Solutions-orange.svg?style=flat&logo=openjdk&logoColor=white) 

Выполнение **учебных** проектов (задания с интенсива), направленных на изучение языка Java (версии 1.8).

## Результат выполненных заданий:
1. Базовые конструкции языка (**00-BasicLanguageConstructs**)
2. ООП и коллекции (**01-OOPСollections**)
3. Файловая система (**02-FileSystem**)
4. Основные механизмы многопоточности (**03-BasicMultithreadingMechanisms**)
5. Библиотеки (**04-Library**)
6. Консольная игра (**05-ConsoleGame**)
7. Механизмы работы с СУБД PostgreSQL через JDBC (**06-JDBC**)
